ENDPOINTS API NUEVOS:

1. POST /api/imagenes/
   • Carga radiografía con validación bioseguridad DICOM
   • Estado inicial: Pendiente
   • Auditoría: SUBIDA_REALIZADA

2. POST /api/imagenes/{id}/procesar_ia/
   • Dispara tarea asincrónica Celery
   • Estado: Procesando
   • Retorna: task_id
   • Auditoría: IA_INFERENCIA_INICIADA

3. GET /api/imagenes/{id}/estado_procesamiento/
   • Verifica estado actual
   • Retorna hallazgos_ia, hallazgos_manuales, estado_tarea
   • Verifica si tiene imagen anotada

4. POST /api/imagenes/{id}/diagnostico_manual/
   • Recibe hallazgos: [{etiqueta, bounding_box, observaciones}]
   • Dibuja cuadros rojos en imagen
   • Guarda imagen_anotada
   • Merge con IA si existen hallazgos_ia
   • Auditoría: DIAGNOSTICO_MANUAL_REGISTRADO

5. GET /api/imagenes/{id}/descargar_imagen_anotada/
   • Descarga PNG con anotaciones

AUDITORÍA AUTOMÁTICA:

Todos los eventos quedan registrados en HistorialAuditoriaImagen:

✓ SUBIDA_REALIZADA
✓ IA_INFERENCIA_INICIADA
✓ IA_INFERENCIA_COMPLETADA
✓ DIAGNOSTICO_MANUAL_REGISTRADO

Campos registrados:
- estudiante (quién)
- docente (supervisor)
- paciente (a quién)
- timestamp (cuándo)
- detalles (qué - JSON)

PRÓXIMOS PASOS PARA EJECUTAR:

1. Instalar dependencias:
   pip install -r requirements.txt

2. Aplicar migraciones:
   python manage.py makemigrations
   python manage.py migrate

3. Ejecutar Redis:
   redis-server
   (O: docker-compose up redis)

4. Iniciar Celery worker (en otra terminal):
   celery -A backend worker -l info

5. Ejecutar Django (en otra terminal):
   python manage.py runserver

6. Verificar instalación:
   python verificar_arquitectura_ia.py

7. Ejecutar pruebas:
   python test_arquitectura_ia.py
