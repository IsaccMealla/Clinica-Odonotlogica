PASO 1: CLONAR Y CONFIGURAR

☐ cd d:\Clinica-Odonotlogica
☐ python -m venv venv (o tu gestor de venv preferido)
☐ source venv/Scripts/activate (Windows: venv\Scripts\activate)

═════════════════════════════════════════════════════════════════

PASO 2: INSTALAR DEPENDENCIAS

☐ pip install --upgrade pip
☐ pip install -r requirements.txt

   Si tienes problemas con PyTorch/TensorFlow, instalar por separado:
   ☐ pip install torch (o tu versión específica)
   ☐ pip install tensorflow (opcional)
   ☐ pip install onnxruntime

═════════════════════════════════════════════════════════════════

PASO 3: CONFIGURAR REDIS

Opción A - Nativo:
☐ Descargar Redis de https://redis.io/download
☐ redis-server (en terminal separada)

Opción B - Docker:
☐ docker-compose up -d redis
☐ docker ps (verificar que está corriendo)

Verificar conexión:
☐ redis-cli ping (debe retornar PONG)

TROUBLESHOOTING:

Problema: "No module named pydicom"
Solución: pip install pydicom

Problema: "Connection refused (Redis)"
Solución: 
  - Verificar que redis-server está ejecutándose
  - O ejecutar: docker-compose up redis

Problema: "Celery worker no inicia"
Solución:
  - Verificar Redis está corriendo
  - Verificar CELERY_BROKER_URL en settings.py

Problema: "Migration conflicts"
Solución:
  - python manage.py showmigrations
  - python manage.py migrate gestion_clinica

Problema: "ImagenClinica model error"
Solución:
  - Verificar que models.py tiene los nuevos campos
  - Ejecutar: python manage.py makemigrations --name add_ia_fields
  - python manage.py migrate
